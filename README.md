# Clean React Native app

This project was cleaned from Expo and converted to a plain React Native app.

## Quick start

```bash
npm install
npx react-native start
```

On macOS for iOS:

```bash
npx react-native run-ios
```

For an unsigned IPA build through an iOS build service, use a standard React Native iOS project generated by the React Native CLI and then build it with Xcode or a CI iOS builder.

## Notes

- No Expo packages or Expo config are left in this project.
- The app uses plain React Native instead of Expo-managed workflows.
- This setup is suitable for an iOS builder that expects a standard native iOS project.
